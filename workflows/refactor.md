# Workflow: Refactor

> Steps for refactoring code.

---

## Pre-Work

1. Read context files for affected areas
2. Understand current implementation
3. Identify:
   - What to improve
   - Impact on other components
   - Breaking changes

---

## Planning

1. Document refactor goals
2. List all affected files
3. Plan order of changes (minimize breakage)
4. Get user approval if significant

---

## Implementation

1. Make changes incrementally
2. Test after each step
3. Update context files as you go
4. Preserve functionality (unless intentional change)

---

## Post-Work

1. Update all affected context files
2. Log decisions with rationale
3. Add new patterns if applicable
4. Update INDEX.md if structure changed
